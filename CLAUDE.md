# Pravidla projektu
- Push do větve `main` = změna je za cca 1 minutu živě na https://janku.stchstudio.cz (Vercel).
- Po každé ucelené změně se mě zeptej: „Chceš to nahrát na web?" Commit a push dělej JEN po mém výslovném souhlasu.
- Před pushem ověř, že projekt jde sestavit (např. `npm run build`, pokud existuje). Když build selže, nepushuj a oprav to.
- Commit zprávy piš česky a srozumitelně.
- Nikdy necommituj .env, hesla, tokeny ani node_modules. Repozitář je veřejný.
- Nikdy nepoužívej `git push --force`.
- Do žádného souboru v repu nikdy nezapisuj token z git remote URL.
- Když push selže kvůli přístupu (401/403), nezkoušej se přihlašovat. Napiš mi, ať kontaktuju Radka.
